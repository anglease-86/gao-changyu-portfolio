# 高长宇个人主页预览

以 Alche Studio 的空间构造与滚动叙事为视觉参考，制作高长宇的个人简历和项目作品网站。包含姓名开场、首页、横向作品、个人介绍、工作方法和联系章节。正文根据提供的简历整理。

## 本地预览

在此目录运行：

```sh
python3 server.py
```

打开 http://127.0.0.1:4173。需要通过本地服务器访问，直接双击 HTML 无法加载浏览器的 ES 模块。

## 内容与效果

- `index.html`：个人文案与页面结构。
- `style.css`：版式、响应式布局与姓名转场。
- `app.js`：姓名开场、跳过与重播、章节状态、横向作品轨道、项目前后切换、项目详情弹层和键盘交互。
- `scene.js`：Three.js 立体三角线框、摄影棚反射、棱边彩色流光、圆形构造线、空间网格，以及随章节移动和旋转的镜头构图。空闲动画最高 30 帧/秒，页面隐藏时停止渲染。
- `assets/projects/`：六张会展、论坛、展厅与节庆空间的概念渲染示意，增加舞台灯光和人物尺度参照，不代表实际项目照片。
- `preview/project-art.html`：项目空间示意的 Three.js 生成源文件，可用于重新渲染素材。
- `assets/vendor/`：本地保存的 Three.js 0.170.0，附 MIT 许可证。运行页面时无需连接第三方 CDN。

字体使用本地 Antonio 与 Noto Sans SC 子集，图标使用 Lucide 路径；许可证随资源保存。运行时不依赖外部字体或脚本服务。

系统开启“减少动态效果”时跳过开场，项目以普通列表呈现，取消自动旋转与流光。导航栏提供场景动画暂停和开场重播按钮。开场与项目详情都支持 Escape 关闭。WebGL 不可用时显示静态线框结构；JavaScript 关闭时保留普通作品列表和可展开的项目说明。

当前为本地预览，尚未公开部署。真实项目图片和更完整的项目资料可以继续替换到现有作品结构中。
